VERSION: 2.2.3 (2026-11-20)
Backup Utilities (userbackup)
-----------------------
* Synchronized logic: The script (now v2.1.14) is fully updated to match the latest stability fixes in the main diskbackup tool.
* SMB/Symlink fix: Resolved the "Operation not supported (95)" network error by implementing --no-links in the main copy phase to silently skip Windows shortcuts.
* Optimized UX: Introduced --info=progress2, --info=nonreg0, and -h throughout the script (including SPCS/SIE data and the explicit OneDrive copy) for clean, readable progress bars in the terminal.
* Seamless integration: Automatically reads the order number via /tmp/alina_order just like the rest of the tools, minimizing manual input.

VERSION: 2.2.2 (2026-11-19)
Disk Management & Mounting (hddmount)
-----------------------
* New NTFS Driver: Transitioned from ntfs-3g to the built-in and significantly faster ntfs3 kernel driver for superior transfer speeds.
* Self-healing mounting: The script now automatically detects "dirty" file systems (due to Windows Fast Startup or crashes), runs ntfsfix -d in the background, and retries the mount, saving technicians from manual troubleshooting.
Backup Utilities (diskbackup)
-----------------------
* SMB/Symlink fix: Resolved the "Operation not supported (95)" error on the backup server. The script now uses --no-links in phase 1 to ignore old Windows shortcuts (like "Documents and Settings") but retains the function to force OneDrive cloud files in phase 2.
* Optimized UX: Updated rsync flags (--info=progress2, --no-i-r) now provide a clean, single, and much more readable progress bar instead of spamming the terminal with filenames.
* Updated Blacklist: Added Program Files/WindowsApps to the exclusion list and an exception for damaged /LogFiles.
* Seamless integration: The script now automatically reads the order number from /tmp/alina_order just like the other tools.
System
-----------------------
* Stability: Permanently removed the problematic broadcom-wl package from the installation list to prevent crashes during ISO building.

VERSION: 2.2.1 (2026-10-16)
Disk Clones
-----------------------
* New tool (clone-disk): Added a dedicated tool for cloning disks (using dd under the hood). The tool handles bad sectors safely with conv=noerror,sync.
* Two working modes: Supports both creating Image files (.img) directly to the backup server and direct cloning (Disk-to-Disk).

VERSION: 2.2.0 (2026-09-04)
SYSTEM & CORE (Archiso)
-----------------------
* Native BitLocker Integration: Completely removed the unstable 'dislocker' tool and its dependencies from the ISO build and local custom repository. Transitioned to Arch Linux's built-in and modern 'cryptsetup', providing much faster and more stable BitLocker unlocking directly in the OS.
BITLOCKER UTILITY ('bitlocker' v2.2.0)
-----------------------
* Cryptsetup Rewrite: Rewrote the entire decryption logic to utilize 'cryptsetup'. Added dynamic naming (mapper handling) to avoid system conflicts, allowing you to unlock and mount multiple BitLocker disks simultaneously.
* Automatic Network Sync: The script now silently restarts the Samba service upon a successful unlock. This ensures the newly decrypted disk immediately becomes available over the network for your Windows machines.

VERSION: 2.1.10 (2026-08-15)
BACKUP UTILITIES ('diskbackup' & 'userbackup' v2.1.13)
-----------------------
* Improved Windows App filtering: Replaced specific app exclusions with a comprehensive rule that now excludes the entire 'AppData/Local/Packages' folder. This significantly speeds up copying and saves a lot of space.
* Antivirus Cache Exclusion: Added new global exclusions for heavy and unnecessary folders from Norton, AVG, Avast, and McAfee (both in AppData/Local and LocalLow). This prevents enormous amounts of junk data, logs, and virus signatures from being copied unnecessarily.

VERSION: 2.1.9 (2026-08-13)
SYSTEM & CORE (Archiso)
-----------------------
* Native OneDrive Support: Integrated the 'ntfs-3g-onedrive' plugin directly into the ISO build. The LiveCD can now read and mount Windows 10/11 "Files On-Demand" (reparse points) without treating them as broken symlinks.
* Dynamic Network Sharing: Added 'samba' and 'wsdd' packages. The LiveCD now automatically broadcasts mounted disks (like /mnt/disk1) securely over the local network to Windows computers.
* Terminal Session Fix: Resolved the infinite loop bug in the autostart profile. Exiting the menu now drops the user directly into a working terminal session.
MAIN MENU ('menu' v2.1.14)
-----------------------
* Automated SMB Sharing: The menu now silently configures and starts a secure Samba network share in the background at startup, locked to the 'root' user.
* Interface & Navigation: Navigation keys are now uppercase (X, R, Q). Option 14 has been explicitly renamed to "Change Ordernumber".
* S.M.A.R.T. Health Check: Refined hardware check logic to detect empty connections, showing a clear warning ("No physical disks detected") instead of false S.M.A.R.T. errors.
BACKUP UTILITIES ('diskbackup' & 'userbackup' v2.1.12)
-----------------------
* Offline Flexibility: Removed the hard network block. Technicians can now perform local or custom backups (e.g., to USB drives) even when the backup server is offline.
* Advanced OneDrive Copying: Added a targeted secondary rsync phase specifically for OneDrive folders to ensure local cloud files are physically copied.
* Smart Cloud Handling: Both scripts now gracefully skip broken symlinks in Windows profiles (like 'Default User') to prevent crashes. They also warn in plain text if a customer's data only exists in the cloud.
WINDOWS NETWORK TOOL ('NEW_alina_local_backup.cmd' v2.1)
-----------------------
* Secure Authentication: Updated mounting logic ('net use') to connect to the LiveCD's new secure Samba share using 'root' credentials, replacing the old insecure guest access.
