Version: 2.2.4
Date: 2026-11-20

Diagnostics & Hardware (hardware & smart)
-----------------------
* Modernized NVMe Commands: Updated the syntax from the deprecated 'nvme smart-log' to the current 'nvme log smart' to prevent terminal warnings and ensure compatibility with the latest nvme-cli package.

Version: 2.2.3
Date: 2026-11-20

Backup Utilities (userbackup)
-----------------------
* Synchronized Logic: The userbackup script is now fully updated to match the latest stability fixes in the main diskbackup tool.
* SMB/Symlink Fix: Resolved the "Operation not supported (95)" network error by implementing --no-links in the main copy phase to silently skip legacy Windows shortcuts.
* Optimized UX: Introduced --info=progress2, --info=nonreg0, and -h throughout the script (including SPCS/SIE data and the explicit OneDrive copy) for clean, readable progress bars.
* Seamless Integration: Automatically reads the order number via /tmp/alina_order to minimize manual input.

Version: 2.2.2
Date: 2026-11-19

Disk Management & Mount (hddmount)
-----------------------
* New NTFS Driver: Transitioned from ntfs-3g to the native and significantly faster ntfs3 kernel driver for superior transfer speeds.
* Self-Healing Mount: Automatically detects "dirty" filesystems (due to Fast Startup or crashes), runs ntfsfix -d in the background, and retries the mount seamlessly.

Backup Utilities (diskbackup)
-----------------------
* SMB/Symlink Fix: Implemented --no-links in phase 1 to ignore legacy Windows shortcuts while retaining the ability to force OneDrive cloud files in phase 2.
* Optimized UX: Updated rsync flags for a clean, single progress bar instead of file spam.
* Updated Blacklist: Added Program Files/WindowsApps, LogFiles, $Windows.~BT, and other bloatware/caches to the exclusion list.
* Seamless Integration: Automatically reads the order number from /tmp/alina_order.

System
-----------------------
* Stability: Permanently removed the problematic broadcom-wl package from the installation list to prevent crashes during image building.

Version: 2.2.1
Date: 2026-10-16

Disk Clones
-----------------------
* New Tool (clone-disk): A dedicated disk cloning tool (running dd under the hood) has been added. Safely handles defective sectors using conv=noerror,sync. Supports direct Image file creation (.img) to the backup server and direct cloning (Disk-to-Disk).

Version: 2.2.0
Date: 2026-09-04

SYSTEM & CORE (Archiso)
-----------------------
* Native BitLocker Integration: Completely removed the unstable 'dislocker' tool and its dependencies. Transitioned to Arch Linux's built-in 'cryptsetup' for much faster and more stable BitLocker unlocking.

BITLOCKER UTILITY ('bitlocker' v2.2.0)
-----------------------
* Cryptsetup Rewrite: Rewrote decryption logic to utilize 'cryptsetup'. Added dynamic naming (mapper management) to avoid system conflicts, enabling multiple BitLocker disks to be unlocked and mounted simultaneously.
* Auto Network Sync: The script now silently restarts the Samba service upon successful unlock, making the decrypted disk immediately available over the network.

Version: 2.1.10
Date: 2026-08-15

BACKUP UTILITIES ('diskbackup' & 'userbackup' v2.1.13)
-----------------------
* Improved Windows App Filtering: Replaced specific app exclusions (like Candy Crush) with a comprehensive rule excluding the entire 'AppData/Local/Packages' folder, significantly speeding up copies.
* Antivirus Cache Exclusion: Added global exclusions for heavy and unnecessary folders from Norton, AVG, Avast, and McAfee, preventing useless data and virus signatures from being copied.

Version: 2.1.9
Date: 2026-08-13

SYSTEM & CORE (Archiso)
-----------------------
* Native OneDrive Support: Integrated 'ntfs-3g-onedrive' plugin directly into the ISO build to read Windows "Files On-Demand" (reparse points) without treating them as broken symlinks.
* Dynamic Network Sharing: Added 'samba' and 'wsdd' packages. The LiveCD now automatically broadcasts mounted disks securely over the local network.
* Terminal Session Fix: Resolved an infinite loop bug in the autostart profile. Exiting the menu now drops the user directly into a working terminal session.

MAIN MENU ('menu' v2.1.14)
-----------------------
* Automated SMB Sharing: The menu silently configures and starts a secure Samba share locked to the 'root' user upon boot.
* Interface & Navigation: Navigation keys are now uppercase (X, R, Q). Option 14 explicitly renamed to "Change Ordernumber".
* S.M.A.R.T. Health Check: Refined hardware check logic to detect empty connections and display a clear warning instead of false SMART errors.

BACKUP UTILITIES ('diskbackup' & 'userbackup' v2.1.12)
-----------------------
* Offline Flexibility: Removed hard network stops. Technicians can now perform local or custom backups (e.g., to USB) even when the backup server is offline.
* Advanced OneDrive Copying: Added a targeted secondary rsync phase specifically for OneDrive folders to ensure local cloud files are physically copied.
* Smart Cloud Management: Scripts skip broken symlinks and catch rsync Error 23, warning the technician if client data only exists in the Microsoft cloud.

WINDOWS NETWORK TOOL ('NEW_alina_local_backup.cmd' v2.1)
-----------------------
* Secure Authentication: Updated mount logic ('net use') to connect to the LiveCD's secure Samba share using 'root' credentials, replacing old guest access.
